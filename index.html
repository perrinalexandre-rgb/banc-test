Extraction de données

Extraire l'historique vers Excel

Une ligne toutes les 5 secondes, toutes les grandeurs en colonnes, une feuille Excel par jour couvert. Heures de Paris. L'historique commence au jour de la mise en service de l'archivage — les jours absents sont simplement sautés.

Choisissez la plage, puis « Extraire ». Exemple : hier 10:00 → hier 11:00 = 720 lignes.

Réglages

Modifier la configuration de l'automate

Laissez vide tout ce que vous ne voulez pas changer : seuls les champs remplis partent vers l'automate. Le numéro de version est incrémenté automatiquement — sans quoi l'automate ignorerait le bloc entier. Les bornes ci-dessous sont celles codées en dur dans le firmware.

Actions — envoyées avec la clé ci-dessous, après confirmation, par le même canal que la configuration (champs raz_compteurs / acq_defauts). La remise à zéro est sélective depuis le programme 2308e : le premier clic ouvre le choix des familles. Acquittement pris en charge depuis 2308c. Sur un programme plus ancien, l'envoi est sans effet — seul le numéro de config avance.
